# 📘 Assignment: Python Algorithms

## 🎯 Objective

Learn beginner algorithm skills by working with Python lists, search operations, and simple sorting. Practice writing functions that analyze and transform data using loops and conditionals.

## 📝 Tasks

### 🛠️ Implement list search functions

#### Description

Write functions that search a list for values and return results based on the search.

#### Requirements
Completed program should:

- Implement `find_item_index(items, target)` to return the index of `target` or `-1` if not found
- Implement `count_occurrences(items, target)` to return how many times `target` appears
- Handle empty lists correctly
- Return the expected numeric results for each function

### 🛠️ Implement simple sorting and transformation

#### Description

Write functions that sort numeric data and create a cleaned list of unique values.

#### Requirements
Completed program should:

- Implement `sort_numbers(numbers)` to return the numbers in ascending order
- Implement `unique_sorted_values(items)` to return sorted unique values from the list
- Preserve input data types and handle duplicate values
- Use only Python built-in list operations and loops
